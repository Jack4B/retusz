# Dodge & Burn v2 Implementation Plan

> Implementation should proceed task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the auto Dodge & Burn so that the slider looks natural up to 100 % (user feedback 0.1.4:
"przy większych wartościach wygląda tragicznie").

**Architecture:** New module `retusz/engine/dnb.py`. All analysis runs on a crop resampled so the face is
exactly `DB_FACE_PX` = 256 px wide (identical for preview and export). It produces one smooth ΔL* field =
blotch evening (mid-frequency band, toward the local skin mean, redescending + tanh-capped) + contour
shaping (soft landmark-placed dodge/burn shapes). The field is applied at full resolution as a
luminance-only gain in linear light (chromaticity kept, so no orange/grey skin), with highlight protection.
High frequencies are never touched because the field itself is smooth.

**Tech Stack:** NumPy, OpenCV (YuNet landmarks), pytest.

**Status (0.1.6):** done; results in `docs/plans/dnb-v2-research.md` ("Measured"). Differences from the plan: the
evening base is a weighted guided filter (WLS and a Gaussian base kept as gate candidates); the full-res step
refines the *mask* with a fast guided filter (the field itself stays smooth); Plastyka 3D also got a face-seeded
subject mask and subject-only normals.

**Spec:** user message t60u + brief (frequency-separation-aware D&B, luminance only, skin-protected,
preview == export, gate metrics at 50 % / 100 %).

## Diagnosis of v1 (0.1.4) – reproduced on box test portraits, sheets in private notes
1. **Orange / over-saturated skin when darkening:** v1 lowered L* and kept a*/b* → chroma relative to
   lightness grows, and LAB→sRGB clips per channel (orange cast on warm skin).
2. **Halos / outlines** at glasses frames, eyes, lips, moustache: the mask-normalised blurs used
   `soft mask > 0.3`, which includes dark frame/brow pixels; the band then over-brightens skin next to them
   and darkens the features' rims ("HDR/grunge" look).
3. **Muddy, flattened face:** the band (fw/60 … fw/8) contains the face's own modelling (cheek/nose shading);
   removing 80 % of it linearly at 100 % flattens shape and greys the skin; no cap per pixel.
4. **Linear, unbounded strength:** 100 % = 0.8 × band with no limit → large features (nostrils, eye
   sockets, wrinkles 30+ L*) get huge corrections.

## Global Constraints
- Only `Jack4B` in code/commits; no private photos in the repo; no Retusz4me/GPL code.
- Preview vs export ΔE < 1. Full-res work in strips (24 Mpx+ originals).
- Slider semantics unchanged (`Params.db` 0..1, default 0.4); brush unchanged.

## Review Focus
- Faces with glasses / beard / moustache: no halos at frames or hair edges (gate: non-skin |ΔL| ring).
- Several faces in one photo, overlapping regions: one union field, no seams.
- Small faces (< 60 px) and no landmarks: evening only, contour from bbox layout, no crash.
- Bright skin near clipping: dodge must not clip (gate: clipped % not increased).
- Very dark skin / low key: correction in L* stays bounded (cap), no grey lift.
